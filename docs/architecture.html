DuckDB

Snapshot fixado, schema mínimo e abertura somente leitura.

Nenhuma query arbitrária atravessa a tool.

Tools estreitas

  • MetricsTool: 4 métricas + 2 suplementos, séries 30d/12m
  • ChartsTool: SVG determinístico e acessível
  • NewsTool: Google News RSS, query/locale/14d/allowlist fixos

Notícia é conteúdo não confiável

Redirects e destinos são validados; texto não controla tools, grafo ou prompt. Sem corpo integral de artigo.

Fronteira do agente

Somente agregados, séries, hashes, metadados e notícias permitidas entram no EvidenceBundle imutável.

OpenAI + fallback

Structured output Pydantic; uma repetição transitória. Falha/rejeição produz comentário factual determinístico.

Validador de claims

IDs devem existir; números devem constar da evidência. Rejeita URL, causalidade, clínica e prompt injection.

Renderer HTML

Escapa conteúdo, mostra qualidade, métodos, períodos, fontes, watermarks, limitações, modo e run_id.

AuditSink

JSONL append-only, flush + fsync antes de OpenAI/publicação; transições, decisões, duração, modelo e hashes — sem segredo/payload bruto.

Run bundle atômico

  • request.json
  • evidence.json
  • audit.jsonl
  • charts/*.svg
  • report.html
  • manifest.json
Diretório candidato é validado e renomeado; run_id nunca é sobrescrito.

Invariantes de governança

Golden exige execução live, métricas nacionais disponíveis, gráficos completos, notícia recente, claims OpenAI válidas, hashes e evento crítico. Degradação demonstra resiliência, mas não substitui o golden.
